пять режимов, одна платформа

Учи 1С в браузере — от Сообщить("привет") до отчёта по регистру.

Интерпретатор BSL, песочница языка запросов SDBL, ноутбук с исполняемыми ячейками и справочник с doctest-ами — всё в одном PWA, без десктопной 1С. Выбирай режим ниже.

01 · интерпретатор

▶Тренажёр

Пиши BSL и сразу видишь, как считает интерпретатор. Автодополнение из справочника, отладчик со стеком и переменными, ссылка «поделиться» — код едет в URL и никуда не уходит с твоей машины. 

// Быстрое «привет»
Сообщить("Здравствуй, 1С");

Функция Факториал(Н) Экспорт
    Если Н <= 1 Тогда
        Возврат 1;
    КонецЕсли;
    Возврат Н * Факториал(Н - 1);
КонецФункции;

05 · judge

⚖Задачник

Коллекции задач из книг с автопрогонкой тестов. Пиши решение — песочница сравнивает вывод с эталоном. Задачи-запросы работают точно так же: сверяем rowset с ожидаемым. 

// Задача: развернуть строку

Функция Развернуть(С) Экспорт
    Р = "";
    Для и = СтрДлина(С) По 1 Цикл
        Р = Р + Сред(С, и, 1);
    КонецЦикла;
    Возврат Р;
КонецФункции;

// ✓ test 1: "abc" → "cba"
// ✓ test 2: "мир" → "рим"
